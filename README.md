# Sistema de controle financeiro pessoal:
Sistema de controle financeiro desenvolvido com python usando a biblioteca
customtkinter para fazer a interface gráfica.

# Funcionalidades:
- Cadastro de receitas e despesas
- Consulta de saldo
- Histórico de movimentações

# Tecnologias:
- Python
- Customtkinter

# Como executar?
Instale as dependencias:

pip install -r e requirements.txt

Execute o programa:

python main.py
